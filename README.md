个人项目：Unity 2D 俯视角射击生存游戏
开发时长：个人独立开发技术栈：Unity + C#、多场景架构、单例管理器、对象池、A * 寻路、事件中心、UGUI
项目简介
独立开发一款 2D 俯视角波次射击生存游戏，采用 **“持久化管理器场景 + 业务场景分离” 的模块化架构 **，将核心管理器与关卡、UI 等业务模块解耦，实现玩家射击生存、多关卡敌波刷新、AI 智能追击与全局状态管控，完成从架构设计到全线 Bug 修复的完整开发流程。
核心亮点

模块化架构设计：通过多单例管理器分工协作，GameStateManager 管控游戏全局状态，WaveManager 管理关卡波次，PoolManager 优化对象复用，实现高内聚低耦合；跨场景 UI 递归查找解决弹窗引用丢失问题。
核心系统开发：实现玩家移动、多枪械射击、血量 / 子弹系统；AI 敌人基于 A * 寻路自动追击，支持环形弹幕攻击与死亡机制；关卡通关 / 失败自动触发对应流程与玩家锁操作。
性能优化与问题解决：搭建敌人对象池减少实例化开销；通过事件中心解耦模块通信；修复对象池状态残留、跨场景功能失效等工程 Bug。

项目收获
熟练掌握 Unity 多场景架构、状态机、对象池、A * 寻路等技术实战，具备独立完成游戏架构设计、模块开发与问题排查的能力。
